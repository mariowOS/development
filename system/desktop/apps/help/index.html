Welcome to mariowOS

mariowOS is a revolutionary, modular, and lightweight web-based desktop environment. Designed from the ground up for speed, minimalism, and high contrast, it provides a seamless user experience that feels both familiar and fundamentally modern.

speed
Built for Performance

By leveraging modern web technologies and keeping the core system extraordinarily light, mariowOS ensures instant boot times and snappy application responses, even on lower-end hardware.

web_asset Navigating the UI

The interface is built with highly responsive layouts that seamlessly adapt to your workflow, whether you are on a desktop monitor or a portable touch device.

Background Worker Threads

Unlike traditional operating systems that can hang when a single app misbehaves, mariowOS guarantees complete system stability. Intensive tasks and heavy computations are automatically offloaded to background worker threads.

info

This asynchronous architecture guarantees that the main user interface never freezes. You can continue interacting with the desktop while complex tasks run silently in the background.

palette Personalization

Making mariowOS your own is incredibly straightforward. Head over to the Wallpaper & Style or Lockscreen settings to adjust your desktop's visual footprint.

Powered by monet-engine

At the heart of the UI customization is the custom-built monet-engine. When you change your wallpaper, this engine dynamically extracts an optimized color palette from the image.

  • System-wide Accents: Buttons, toggles, and highlights automatically adjust to complement your background.
  • Smart Contrast: The engine ensures that text remains highly legible by calculating appropriate contrast ratios on the fly.

shield_lock Security & Privacy

At the core of mariowOS is a profound commitment to your privacy and security. The system architecture is designed to prevent unauthorized access by default.

Strict Process Sandboxing

mariowOS utilizes strict process sandboxing. There is a hard separation between user applications and the system core. Applications run in isolated environments; they cannot read or write to sensitive system files or access data from other apps without your explicit permission.

lock
Mandatory Authentication

Sensitive actions—such as modifying network configurations, resetting the system, or granting elevated app permissions—will always trigger a mandatory secure password prompt. The system will not proceed without verifying your identity.

wifi Connectivity & Updates

Managing your digital connections is straightforward via the built-in Settings panel. mariowOS provides native interfaces for managing Wi-Fi, Bluetooth, and Ethernet networks instantly.

The Updater

Keeping your system secure and equipped with the latest features is handled entirely by the built-in Updater application.

  • Secure Mirrors: Updates are securely fetched from verified mariowOS remote mirrors.
  • Modular Upgrades: Because of the system's modular nature, many updates apply instantly without requiring a full system reboot.

science Functions Lab

For power users, developers, and early adopters, mariowOS includes a dedicated space known as the Functions Lab, accessible via the System Settings.

The Functions Lab is where you can toggle experimental tools, advanced developer features, and beta API access for your workspace.

warning
Proceed with Caution

Features contained within the Functions Lab are actively in development. While exciting, enabling them may cause unexpected behavior or temporary system instability. Use these features primarily for testing and development purposes.
